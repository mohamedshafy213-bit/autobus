# منظومة الأتوبيسات لحفل التخرج (LAN Client/Server)

نظام متكامل لإدارة وتنظيم تسكين أسر الخريجين في الأتوبيسات عبر شبكة محلية سلكية (Ethernet LAN) بدون الحاجة إلى اتصال بالإنترنت.
تعمل قاعدة البيانات في جهاز خادم رئيسي (Server Laptop) وتتصل باقي الأجهزة عبر المتصفح فقط مع ضمان منع التعارض بنسبة 100%.

---

## 🚀 التقنيات المستخدمة
- **الخادم (Server):** Node.js + Express + `better-sqlite3` (قاعدة بيانات `data/buses.db` بنمط WAL والتحقق من Foreign Keys).
- **الواجهة (Client):** Vue 3 (Composition API) + Vite + Tailwind CSS + PrimeVue v4 (Aura Theme) + SheetJS (XLSX).
- **الخطوط واللغة:** خطوط Cairo و Tajawal مدمجة محلياً (تعمل Offline تماماً)، واجهة كاملة باللغة العربية مع دعم RTL.

## 🛠️ دليل التثبيت والتشغيل خطوة بخطوة على Windows

### الخطوة 1: توصيل الأجهزة بكابل الشبكة (Ethernet)
- قم بتوصيل لابتوب السيرفر بلابتوب البوابة أو باقي الأجهزة عبر كابل شبكة (Ethernet) مباشرة أو عبر سويتش/راوتر محلي (Switch/Router).

### الخطوة 2: ضبط العناوين الثابتة (Static IP) في حال عدم وجود راوتر/DHCP
إذا كنت تستخدم كابلاً مباشراً بين الجهازين دون راوتر، اضبط العناوين الثابتة كالتالي:
1. افتح **Control Panel** ثم **Network and Sharing Center** ثم **Change adapter settings**.
2. اضغط كليك يمين على **Ethernet** واختر **Properties**.
3. اختر **Internet Protocol Version 4 (TCP/IPv4)** واضغط **Properties**.
4. اضبط الإعدادات كالتالي:
   - **لابتوب السيرفر (Server):**
     - IP address: `192.168.1.10`
     - Subnet mask: `255.255.255.0`
     - Default gateway: (اتركه فارغاً)
   - **لابتوب العميل / البوابة (Client):**
     - IP address: `192.168.1.11`
     - Subnet mask: `255.255.255.0`
     - Default gateway: (اتركه فارغاً)

### الخطوة 3: فتح المنفذ 3000 في جدار حماية ويندوز (Windows Firewall)
على **لابتوب السيرفر فقط**، افتح موجه الأوامر (Command Prompt أو PowerShell) كمسؤول (**Run as Administrator**) ونفذ الأمر التالي لفتح المنفذ 3000:
```cmd
netsh advfirewall firewall add rule name="Autobus LAN Server" dir=in action=allow protocol=TCP localport=3000
```

### الخطوة 4: تشغيل السيرفر
يمكنك تشغيل السيرفر بإحدى طريقتين:
1. **بالضغط المزدوج على ملف:** `start.bat` الموجود في المجلد الرئيسي.
2. أو من خلال الطرفية (Terminal):
   ```bash
   npm run start
   ```

عند الإقلاع، سيطبع السيرفر رسالة ترحيبية تعرض عنوان الـ LAN، على سبيل المثال:
```text
افتح من أي جهاز آخر: http://192.168.1.10:3000
```

### الخطوة 5: فتح المنظومة من الأجهزة الأخرى
افتح متصفح الويب (Chrome / Edge) من أي لابتوب متصل واكتب:
```text
http://192.168.1.10:3000
```
ستظهر المنظومة وتعمل فوراً مع تحديث لحظي للبيانات كل 3 ثوانٍ وفور تنفيذ أي إجراء.

## 🧪 اختبارات التزامن ومنع التعارض (Concurrency Tests)
المنظومة مزودة بسكريبت اختبار شامل للتأكد من استحالة حدوث تعارض:
- **الاختبار الأول:** إرسال 20 طلب تسكين متزامن في نفس الجزء من الثانية لنفس العائلة (ينجح طلب واحد فقط ويتم رفض 19 بـ `ALREADY_SEATED`).
- **الاختبار الثاني:** إرسال طلبات متزامنة لعدة طلاب تتجاوز سعة الأتوبيس (يقبل الأتوبيس حد سعته فقط ويرفض الزائدين بـ `BUS_FULL`).
- **الاختبار الثالث:** استيراد الطلاب من ملف Excel والتحقق من منع التكرار والتحقق من سلامة الأرقام القومية.

لتشغيل الاختبارات:
```bash
npm run test:concurrency
```

## 📁 أوامر التطوير والتشغيل (NPM Scripts)
- `npm run dev`: تشغيل السيرفر والواجهة معاً في بيئة التطوير (مع التحديث التلقائي).
- `npm run build`: بناء ملفات الواجهة وتصديرها إلى `server/public`.
- `npm run start`: تشغيل سيرفر الإنتاج لتوزيع التطبيق عبر الشبكة المحلية.
- `npm run test:concurrency`: تشغيل فحص التزامن ومنع التعارض.
